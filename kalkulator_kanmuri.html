            /______\

          ==============  <-- Nok (KFF2)
               /\
              /  \
             /    \
3 Jurai Luar

Garis miring luar pertemuan bidang atap. Dipasang Nok KFF2 & Ujung Jurai KFF6.

                 /\

  Jurai Luar ->/    \<- Jurai Luar
              /  /\  \
4 Jurai Dalam / Talang

Lembah atap tempat aliran air hujan. Menggunakan Genteng Talang KFF12 / Talang Seng.

             \        /
              \      /   <-- Jurai Dalam
               \    /        (Valley Tile)
                \  /
5 Starter / Lisplang

Sisi tepi samping dan bawah atap. Menggunakan Lisplang Kiri KFF3 & Kanan KFF4.

             /      \
            /        \
   =========          ========= 
   [KFF3] Lisplang    [KFF4] Lisplang
